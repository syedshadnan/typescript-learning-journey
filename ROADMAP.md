# TypeScript Learning Roadmap

This roadmap is designed to take you from beginner-level TypeScript knowledge to building real-world applications with confidence.

## How to Use This Roadmap

- Learn one phase at a time.
- Practice each concept by building a small example or mini-project.
- Keep notes in your learning log after every milestone.
- Move on only when you can explain the topic in your own words and use it in code.

---

## Phase 0 — Setup and Foundations

Goal: Understand the purpose of TypeScript and prepare your development environment.

Topics:
- What TypeScript is and why it is useful
- Installing TypeScript and Node.js
- Creating and understanding tsconfig.json
- Running TypeScript files with the compiler
- Reviewing JavaScript basics that matter in TypeScript

Status: ✅ Completed

---

## Phase 1 — TypeScript Fundamentals

Goal: Write simple, typed programs with confidence.

Topics:
- Primitive types
- Arrays and tuples
- Objects
- Functions
- Optional and default parameters
- Union types
- Type inference

Practice Goal:
- Build a small calculator or number guessing game

Status: ⏳ Not Started

---

## Phase 2 — Object Typing

Goal: Model data clearly and safely.

Topics:
- Type aliases
- Interfaces
- Optional properties
- Readonly properties
- Literal types
- Enums

Practice Goal:
- Create a typed user/profile model for an app

Status: ⏳ Not Started

---

## Phase 3 — Advanced Types

Goal: Write flexible and reliable code.

Topics:
- Intersection types
- Type guards
- Type narrowing
- Discriminated unions
- Utility types

Practice Goal:
- Build a small API response parser with strong typing

Status: ⏳ Not Started

## Phase 4 — Generics

Goal: Create reusable and type-safe components.

Topics:
- Generic functions
- Generic interfaces
- Generic classes
- Constraints
- Common built-in generics

Practice Goal:
- Create a typed data container or reusable form helper

Status: ⏳ Not Started

Goal: Organize larger applications using classes and design patterns.

- Classes

- Abstract classes

- Build a small library or inventory system

Goal: Build modern frontend apps with strong typing.

- Event handling

Practice Goal:
- Build a typed To-Do app or dashboard

Status: ⏳ Not Started

## Phase 7 — Backend TypeScript

Goal: Build typed server-side applications.

Topics:
- Node.js with TypeScript
- Express.js
- API route typing
- Middleware and error handling
- Working with databases

Practice Goal:
- Create a small CRUD API with typed request and response models

Status: ⏳ Not Started

---

## Phase 8 — Real-World Projects

Goal: Apply everything you learned in complete projects.

Suggested Projects:
- User Manager App
- Expense Tracker
- React + TypeScript Frontend
- Full-Stack Task Manager
- Blog or Portfolio App with TypeScript

Project Checklist:
- Use TypeScript throughout the app
- Add clear types for data and functions
- Include a README with setup instructions
- Deploy or share the project when possible

Status: ⏳ Not Started

## Milestones

By the end of this roadmap, you should be able to:
- Write typed JavaScript applications with TypeScript
- Use interfaces, types, and generics effectively
- Build frontend and backend apps with TypeScript
- Create projects that are easier to maintain and scale

## Suggested Timeline

- Week 1–2: Setup + Fundamentals
- Week 3–4: Object Typing + Advanced Types
- Week 5: Generics
- Week 6: OOP
- Week 7–8: React + TypeScript
- Week 9–10: Backend + APIs
- Week 11+: Projects and portfolio building
